# Soft Systems Methodology and VFT reconciliation

SSM is a learning system for plural, problematical situations, not an optimizer that discovers one objective problem or one final solution.

## Seven-stage operational model

1. Enter the situation considered problematical without prematurely naming a single problem.
2. Express it with a structured rich picture plus Analysis 1 (intervention roles), Analysis 2 (social roles, norms, values), and Analysis 3 (power and control).
3. Formulate relevant transformations, CATWOE, and root definitions in PQR form.
4. Build conceptual models of logically necessary purposeful activities, monitoring, control, and measures such as efficacy, efficiency, effectiveness, ethicality, and elegance where applicable.
5. Compare conceptual models with observed reality to create questions and gaps, not to score reality against an ideal design.
6. Debate changes separately for systemic desirability and cultural feasibility. Preserve disagreement.
7. Define action to improve the situation, owners, learning measures, and the next iteration.

## CATWOE

- Customers affected by transformation.
- Actors who perform it.
- Transformation from input state to output state without changing abstraction level.
- Weltanschauung that makes it meaningful.
- Owner able to stop or change it.
- Environmental constraints taken as given for this model.

Create multiple root definitions when legitimate worldviews differ. Do not average them into false consensus.

## Mandatory reconciliation back to VFT

Produce a delta table for every SSM finding that affects `STK-*`, `VAL-*`, `OBJ-*`, decision perspective, scope, assumptions, alternatives, or attributes. Each row is `add`, `revise`, `split`, `supersede`, or `retain-with-dissent`, with rationale and source.

Re-run WITI and control-of-consequences for changed objectives. STPA cannot start until the revised baseline is explicitly approved.
