# Biblioteca documental generalista

22 modelos derivados do estudo estrutural e visual de 22 arquivos locais: 21 PDFs (51 páginas) e um Markdown.

A finalidade é reutilizar forma, organização e linguagem visual em outros negócios. Os modelos não contêm conclusões, preços, perfis ou premissas do negócio-fonte. O estudo dos originais está separado da estrutura preenchível.

Abra [INDICE.html](./INDICE.html) para navegar visualmente ou use os modelos abaixo. Cada modelo acompanha JSON de entrada vazio e SVG editável. As páginas HTML permitem editar campos temporariamente e imprimir em PDF; não gravam alterações automaticamente.

## Como usar

1. Leia o [guia de uso](GUIA-DE-USO.md) e escolha os documentos aplicáveis à pergunta decisória.
2. Preencha os dados reais do novo negócio; use null/desconhecido para lacunas e registre fontes.
3. Copie a seção “Modelo preenchível” do Markdown e substitua campos e instruções.
4. Adapte o SVG ou construa a figura a partir do brief; nenhuma marcação visual vazia é resultado factual.
5. Revise consistência entre documentos e aplique os critérios específicos antes de entregar.
